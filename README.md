# EDU_Hotspot

Crie hotspots interativos em imagens com balões de texto, áudio MP3, tradução em tempo real e exportação/importação JSON.

## Recursos
- **Hotspots Interativos**: Adicione pontos em qualquer imagem para exibir informações.
- **Áudio Personalizado**: Suporte para arquivos MP3 externos ou Voz do Sistema (TTS).
- **Modo de Edição**: Arraste e solte os hotspots para reposicioná-los facilmente.
- **Exportação Standalone**: Baixe um arquivo HTML único e funcional para incorporar em qualquer site.
- **Responsivo**: Funciona em computadores, tablets e celulares.

## Como usar
1. Carregue uma imagem via URL.
2. Ative o modo "Mover Hotspot" para adicionar ou reposicionar pontos.
3. Configure os textos e áudios em "Configurações".
4. Baixe o resultado final em "Baixar HTML".

## Desenvolvimento
```bash
npm install
npm run dev
```
